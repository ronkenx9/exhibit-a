      How EXHIBIT A works

      1. Screen. Evidence is data, never instructions. Text in an exhibit that addresses an AI is quarantined before any model sees it.
      2. Map · SERV Reasoning. A Kronos-audited reasoning prompt maps each exhibit to the reason code's required elements, with SERV prompt guard on and a strict JSON schema. Every fact must carry a verbatim quote.
      3. Verify · code. Each quote is matched against the original exhibit. A quote that isn't there, or that comes from quarantined text, is struck.
      4. Verdict · code. Coverage of required elements decides FIGHT or ACCEPT, with the economics. The model never decides.
      5. Draft · SERV Shadow Agent. The rebuttal is written from verified facts only; SERV's shadow agent validates that every sentence cites an exhibit and nothing is conceded, and revises if not.
      6. Lint · code. Any sentence without a citation to a verified exhibit is struck from the packet. Output maps straight onto Stripe's dispute-evidence fields.
